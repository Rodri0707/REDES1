(ver nota abajo)2. Detalle por tipo de tráﬁco
ICMP (pings)
ping -c 4 www.uam.es
-c 4 = manda 4 y para. Sin -c no para nunca (Ctrl+C).
ARP
sudo arping -I ens33 -c 2 <gateway>
Necesita sudo y -I ens33 (sin -I intenta usar una interfaz que no
existe en Linux).
Alternativa sin instalar nada: ping -c 2 <IP de tu subred que no
hayas usado>. Al no conocer su MAC, tu máquina manda un ARP
antes del ping.
DNS (puerto 53, UDP)
nslookup www.uam.es
dig www.uam.es
Salen 4 paquetes: pregunta A + respuesta, pregunta AAAA +
respuesta.
TCP en general / puerto 80
curl -v http://www.uam.es
Usa http:// (no https) para que vaya al puerto 80 y no al 443.
TCP con hping3 (SYN a mano)
sudo hping3 -S -p 80 -c 3 www.uam.es
-S = ﬂag SYN, -p 80 = puerto, -c 3 = solo 3 paquetes. Verás el patrón:
SYN, SYN-ACK, RST.
HTTPS (puerto 443)
curl https://www.uam.es
En Wireshark verás TCP y TLSv1.x (TLS viaja dentro de TCP).
Tráﬁco hacia una IP concreta
ping -c 3 <IP>
con ﬁltro de captura host <IP>.
NTP (puerto 123, UDP)
No hace falta comando: la VM lo genera sola cada cierto tiempo. Filtro
de captura: port 123 (espera un rato).
ICMPv6 / Router Solicitation
sudo rdisc6 ens33Si no está instalado: sudo apt install ndisc6. Este paquete no lo he
podido comprobar en tu VM, así que mira si existe con which rdisc6.
En tus primeras capturas ya apareció un Router Solicitation solo, sin
generarlo tú.
